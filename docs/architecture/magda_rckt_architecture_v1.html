Gobierno Lovable + Claude

Lovable / Diseño

design/*. UI, layout, responsive, animaciones, assets y copy aprobado. Sin backend, API, secretos, infraestructura o telemetría.

Claude / Ingeniería

feature/* o fix/*. Lee AGENTS.md + CLAUDE.md + docs/knowledge. Mantiene contratos, seguridad y pruebas.

GitHub / Control

PR a main. Build, lint, typecheck, E2E/visual. Sin force push ni reescritura de historia sincronizada con Lovable.

Política IA

  • No inventar servicios o precios.
  • No dar consejo clínico individual.
  • No solicitar datos de pacientes.
  • No exponer secretos/prompts internos.
  • Derivar a Magda en propuestas o decisiones profesionales.
  • RAG solo cuando exista corpus real.
